VRCT **v3.6.1** is a bug-fix release for v3.6.0. It fixes the VR UI being offset and impossible to operate, incoming transcription stopping, and the installer failing behind a proxy. It also adds a position lock for the subtitle overlays.

<!-- truncate -->

## New features

### Subtitle overlay position lock

- Lock the position of the single-line and multiple-line subtitle overlays separately, with the padlock button to the right of the **Position / Rotation** switch in the VR tab.
- While locked, you cannot grab and move the overlay in VR, and you cannot change its position or rotation from the settings screen.
- **Reset to Default Settings** leaves a locked overlay's position as it is.

## Improvements

- **Mic Max Queued Messages** and **Speaker Max Queued Messages** (formerly the "words to hold" settings): these never counted words. They set how many transcribed messages can pile up. The names and descriptions now match this, and if more pile up, the oldest ones are discarded. Behavior has not changed.
- Revised the Korean translation (untranslated text, mistranslations, and particles).

## Bug fixes

- Fixed the VR UI being offset, with buttons that could not be pressed, when the Windows **Text size** setting was not 100%. (#125)
- Fixed incoming transcription stopping until a restart when a translation came back empty. This happened when multiple-line display was on for the subtitle overlay. (#121)
- Fixed the installer failing to download (curl error 7) when Windows uses a proxy, such as with a VPN. (#124)
- Fixed the position of the subtitle overlay or VR UI windows sometimes not being saved when you moved them right after startup.
- Fixed an error dialog appearing for a harmless Python warning.
