# 音声タイピングモード（VR）

音声タイピングモードを使用すると、話しかけるだけでVRアプリケーションにテキストを入力できます。音声は文字起こしされ、OSC統合を必要とせずに、アクティブなVRアプリケーションに自動的にペーストされます。

## 概要

音声タイピングモードは以下のように動作します：

1. **キャプチャ**: マイク経由で音声をキャプチャ
2. **文字起こし**: 音声をテキストに変換
3. **コピー**: テキストをシステムクリップボードにコピー
4. **ペースト**: アクティブなVRアプリケーションにペースト

これにより、VRアプリケーションがクリップボード操作をサポートしている限り、ハンズフリーで音声ベースのテキスト入力が可能になります。

## 有効にする方法

### VRヘッドセット内

1. VRヘッドセットを被ります（SteamVRまたは互換VRランタイムがアクティブ）
2. VRCTコンフィグウィンドウを開く
3. **VRタブ** に移動
4. **音声タイピングモードを有効にする** チェックボックスをチェック
5. **保存** をクリック

:::warning[重要]
音声タイピングモードはVRでアクティブに実行している場合のみ動作します。デスクトップモードではペースト操作はトリガーされません。
:::

## 使い方

### 基本的な使い方

1. **音声タイピングモードを有効にする**（上記参照）
2. **Voice2Chatbox を有効化** - マイク文字起こしを開始
3. **VRアプリケーションのテキストフィールドにフォーカス**
4. **マイクに話しかける**
5. **テキストが自動的にペーストされます**

### 例：VRChatワールド検索

1. VRでVRChatを開く
2. ワールド検索に移動
3. 検索フィールドをクリック（フォーカス）
4. VRCTコンフィグ → VRタブ → 音声タイピングモードを有効化
5. ワールド名を話す（例：「Black Cat」）
6. テキストが検索フィールドに自動表示される
7. Enterを押して検索

### 例：日本語テキスト入力

1. テキスト入力機能を持つVRアプリケーションを開く
2. テキストフィールドをクリックしてフォーカス
3. 音声タイピングモードとVoice2Chatbox を有効化
4. Voice2Chatbox言語を **日本語** に設定
5. 日本語で話す（例：「こんにちは」）
6. 日本語テキストが自動的に文字起こしされてペーストされます

## 設定

### VRタブ設定

**音声タイピングモードを有効にする** (チェックボックス)
- 音声文字起こしが自動的にクリップボードにコピーされ、アクティブなVRアプリケーションにペーストされます

### 関連設定

音声タイピングモードを使用するには、以下も設定してください：

1. **デバイスタブ**: マイクデバイスを選択
2. **文字起こしタブ**: 文字起こしエンジンと言語を選択
3. **メインウィンドウ**: Voice2Chatbox トグルを有効化

詳細は [デバイス設定](/docs/config-device)、[文字起こし設定](/docs/config-transcription)、[音声からテキスト](/docs/feature-guide/voice-to-text) を参照してください。

## 機能

### 多言語サポート

音声タイピングモードは、文字起こしエンジンがサポートするすべての言語に対応しています：

| エンジン | サポート言語 |
|---------|-------------|
| **Whisper** | 99言語以上（日本語、中国語、韓国語、スペイン語、フランス語、ドイツ語など） |
| **Google** | 80言語以上 |

Voice2Chatbox設定で言語を設定してください。

### あらゆるVRアプリで動作

OSCベースの入力（VRChat固有）とは異なり、音声タイピングモードは以下で動作します：
- ✅ VRChat（ワールド検索、設定、あらゆるテキスト）
- ✅ その他のソーシャルVRアプリ
- ✅ チャット機能を持つVRゲーム
- ✅ クリップボードペーストをサポートする任意のVRアプリ

### OSC不要

音声タイピングモードは **OSCを必要としません**。以下を通じて動作します：
- システムクリップボード操作
- ネイティブペースト コマンド
- VRChat OSC統合が無効でも動作

## 制限事項

### 音声タイピングモードが機能しない場合

- ❌ **デスクトップモード** - アクティブなVRセッションでのみ動作
- ❌ **クリップボード非対応** - アプリはペースト操作をサポートする必要があります
- ❌ **文字起こし無効** - Voice2Chatbox が有効である必要があります
- ❌ **マイクなし** - マイクを設定・利用可能にする必要があります

### 精度に関する注釈

音声タイピングモードの精度は以下に依存します：

- **文字起こしエンジンの品質**（Whisperの方がより正確）
- **マイクの品質**（バックグラウンドノイズを軽減）
- **音声の明瞭性**（通常のペースで明確に話す）
- **言語設定**（実際の音声言語と一致させる）
