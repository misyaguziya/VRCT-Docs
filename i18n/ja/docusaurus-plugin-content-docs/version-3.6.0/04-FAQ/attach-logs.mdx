# ログと設定データの添付方法

エラーログと設定データを一緒に送っていただけると、問題解決に繋がりやすいです。以下に、GitHubのIssueにそれらのファイルを添付する方法を説明します。

:::note
ログには以下の5種類があります。
- `config.json`
- `error.log`
- `process.log`
- `freeze_trace.log`
- `crash_trace.log`
:::

## ログの保存場所

デフォルトでは、ログは以下の場所に保存されています：

```
C:\Users\{YourUsername}\AppData\Local\VRCT
```

以下の行をコピーして、エクスプローラーのアドレスバーに貼り付けてください。
```text
%LOCALAPPDATA%\VRCT
```

または、`VRCT.exe` があるフォルダーと同じ場所にあります。
VRCTを起動できる場合は、設定画面の **「高度な設定」** タブにある **「設定ファイルを開く」** からも開けます。



## 添付方法（GitHub）

ログファイル（`config.json`、`error.log`、`process.log`、`freeze_trace.log`、`crash_trace.log`）を、GitHubのIssue編集エリアにドラッグ＆ドロップしてください。
